# New user

A request to make a person known to the service, carrying the identity they are known by elsewhere.

## Invariants

- An external identity is present, and it is not blank.

## Made of / held by

An external identity.

- [User](user.md) — what it becomes once stored.
- [Initialize a new user](../usecases/initialize-a-new-user.md) — what it is handed to.
